# 多语言应急通知撰写与发布前检查工具

面向应急值班、编辑、法务、翻译和发布人员的纯前端发布工作台。项目可离线起草，数据自动保存到浏览器 `localStorage`，刷新或断网后继续编辑。

## 功能

- 按事件类型、严重程度、影响范围、时间窗口和发布渠道配置通知。
- 简体中文、英文、日文等多语言版本并列编辑，可标记必需语言和翻译复核状态。
- 内置台风转移、计划停水、公共安全三类可复用模板。
- 发布前检查必填字段、禁用词、术语一致性、时间冲突、语言缺失和未解决讨论。
- 编辑、法务、翻译、发布人四类角色确认和退回流程。
- 逐句选择正文并添加、解决讨论。
- 锁定最终版本、从锁定稿发起紧急修订，并保留历史版本。
- 基于 LCS 的两版逐句差异比较。
- **汛期排期交接（05 工作台）**：通知按语言版本排列到有限渠道名额，带版本凭据的交接发布。
  - 版本凭据 = 版本号 + 标题 + 正文 + 影响范围的哈希；正文/标题/影响范围保存后，该语言的占用名额与值班长/渠道审核角色确认立即失效重算，未触达语言照常保留。
  - 值班员越权提交未授权渠道会被拒绝；两个值班窗口同时抢占同一渠道仅一人成功，失败方/被盖旧排期留下待处理稿并显示接管人。
  - 断网窗口的抢占写入本地交接包；交接包按通知和版本合并，同一渠道两边都改列为待决项，处理前不能发布。
- `Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 重做、`Ctrl/Cmd+S` 手动保存。

## 技术栈

- Angular 19 + TypeScript
- Nebular UI
- Angular Forms / RxJS
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run start
```

开发服务器监听 `4200`，宿主端口仅由部署时映射，源码未写入 `10025`。

## 汛期排期交接演示剧本

进入「05 · 汛期排期交接」，初始状态为短信网关·简体中文名额由一号窗口（陆远征）占用、值班长已确认。

1. **凭据失效重算**：编辑简体中文标题/正文/影响范围并“保存并换发凭据”，该语言渠道名额与角色确认立即失效（红色“已失效需重抢”），切到 English/日本語可见名额照常保留。
2. **越权拒绝**：切到二号窗口（高澜），对「应急广播」点抢占——该渠道只授权一号窗口，提交被拒绝并记入日志。
3. **同时抢占**：任一语言卡片点「A/B 同时抢占」，只一人成功；失败方在右侧“待处理稿”显示接管人，旧排期被盖同样留稿。
4. **角色确认与发布**：占用窗口依次完成值班长、渠道审核确认（凭据失效时按钮禁用），确认齐全且无待决项后「交接发布」可用。
5. **断网交接**：把某窗口切到断网后抢占渠道，改动进入本地待发队列并可“导出交接包”；对端在线抢占同一渠道后导入交接包，同一渠道两边都改列为待决项，处理前发布按钮禁用，选择采用本地/交接包后门禁解除。

排期引擎为纯函数，可用 `npm run test:schedule` 运行 13 项行为冒烟测试（凭据、抢占、越权、待决项、发布门禁等）。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist/emergency-notice/browser`。

## Docker

```bash
docker build -t sologsb-1025 .
docker run --rm -p 10025:80 sologsb-1025
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10025`。数据仅保存在当前浏览器，不会上传服务器。
